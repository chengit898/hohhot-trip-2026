# 呼和浩特五天四夜

一个适合手机和电脑浏览的呼和浩特旅行地图。

## 功能

- Leaflet 地图与高德地图底图
- 按天路线和时间轴卡片
- 景点坐标与高德导航
- 小红书攻略搜索入口
- 行前确认清单（保存在浏览器本地）

## 分享

启用 GitHub Pages 后，访问：

`https://<GitHub 用户名>.github.io/<仓库名>/`

在 GitHub 仓库中进入 **Settings → Pages**，选择 `Deploy from a branch`，再选择 `main` 分支和 `/ (root)` 文件夹即可。

## 坐标说明

酒店和黄花窝铺入口缺少可靠公开坐标，页面改为高德名称搜索；神泉和乌兰哈达等大范围景区保留区域参考点，导航前请在高德结果中确认官方入口。
